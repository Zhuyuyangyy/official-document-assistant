# 演示场景 3：会议纪要转督办台账

> 用户粘贴会议纪要，Skill 提取责任方、待办事项、截止时间，输出可贴入 Excel 的督办台账表（Markdown 表格或 CSV）。

## 用户输入

用户在智能体对话框中粘贴以下会议纪要：

```
会议纪要

会议要求，办公室于6月18日前完成通知发布。
请财务处负责经费测算，6月25日前提交预算表。
各部门要及时落实材料报送要求。
```

用户说：「把这份会议纪要的待办整理成督办台账。」

## 智能体调用

智能体识别意图为会议督办台账提取，调用确定性校验层脚本：

```bash
# Markdown 表格输出
python scripts/gov_doc_review.py --mode brief --format markdown --input examples/brief/meeting.md

# CSV 输出（带 UTF-8 BOM，Excel 直接打开中文不乱码）
python scripts/gov_doc_review.py --mode brief --format csv --input examples/brief/meeting.md
```

## Skill 输出（Markdown 表格）

```markdown
# 会议督办台账

| 序号 | 责任单位 | 待办事项 | 截止时间 | 原文依据 | 建议状态 |
| --- | --- | --- | --- | --- | --- |
| 1 | 办公室 | 完成通知发布 | 6月18日前 | 会议要求，办公室于6月18日前完成通知发布 | 未开始 |
| 2 | 财务处 | 经费测算，提交预算表 | 6月25日前 | 请财务处负责经费测算，6月25日前提交预算表 | 未开始 |
```

## Skill 输出（CSV，带 UTF-8 BOM）

```
序号,责任单位,待办事项,截止时间,原文依据,建议状态
1,办公室,完成通知发布,6月18日前,会议要求，办公室于6月18日前完成通知发布,未开始
2,财务处,经费测算，提交预算表,6月25日前,请财务处负责经费测算，6月25日前提交预算表,未开始
```

> CSV 文件带 UTF-8 BOM（`\ufeff`），Excel 直接双击打开中文不乱码，可直接贴入任务系统。

## 评委关注点

1. **结构化提取**：从自然语言会议纪要中提取出责任方（办公室/财务处）、待办事项（完成通知发布/经费测算提交预算表）、截止时间（6月18日前/6月25日前），并附原文依据可追溯——不是简单复制原文，而是结构化拆解。
2. **第三句被跳过**：原文第三句"各部门要及时落实材料报送要求"没有明确责任方和截止时间，脚本不会硬凑，直接跳过——避免编造督办事项。这体现了确定性校验层的克制。
3. **CSV 带 BOM**：输出的 CSV 带 UTF-8 BOM，Excel 直接双击打开中文不乱码。这是办公室实际使用的高频场景——督办台账要贴入 Excel 或任务系统。
4. **原文依据列**：每条督办事项都附原文依据，便于会议记录人和督办员核对，避免"台账和纪要对不上"的问题。
5. **建议状态列**：默认填"未开始"，督办员可直接在此基础上更新状态（进行中/已完成/已逾期），无需从零建表。
