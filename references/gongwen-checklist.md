# 公文要素与文种规则速查（对照 GB/T 9704—2012 与《党政机关公文处理工作条例》）

> 本文件是本 Skill 的领域知识库，供智能体层在判断、改写和起草时查阅。脚本只做确定性校验；需要语义判断时，智能体应结合本表。具体条、款、项序号以现行标准正式文本为准。

## 一、主体部分要素清单（GB/T 9704—2012）

| 要素 | 要点 |
| --- | --- |
| 标题 | 由发文机关、事由、文种组成，可省发文机关；一般“关于＋事由＋的＋文种”。除法规、规章名称加书名号外，标题一般不用标点。 |
| 主送机关 | 正文之上、标题之下顶格，主送机关之间用顿号或逗号，回行顶格。 |
| 正文 | 层次序数依次为“一、”“（一）”“1.”“（1）”，不跳级、不混用。 |
| 附件说明 | 正文下空一行左空二字标“附件：”，多个附件用阿拉伯数字顺序号，序号须与正文引用一致。 |
| 发文机关署名 | 成文日期之上署发文机关全称或规范化简称。 |
| 成文日期 | 用阿拉伯数字将年、月、日标全，年份标全称，月、日不编虚位（如 2026年6月1日，不写 2026-06-01，也不写 06月01日）。 |
| 附注 | 需要说明的事项（如联系方式、公开属性）置于成文日期下一行。 |

## 二、常见文种适用范围与易错点

- 通知：发布、传达要求事项，批转、转发公文。正文宜明确对象、事项、时间节点、办理要求。
- 请示：向上级请求指示、批准。**坚持一文一事**；结语规范用“妥否，请批示”“当否，请批复”。
- 报告：向上级汇报工作、反映情况、答复询问。**不得夹带请示事项**；需审批事项另行行文请示。
- 函：不相隶属机关之间商洽工作、询问答复、请求批准。语气平实商洽，不用命令式。
- 通报：表彰先进、批评错误、传达重要精神或情况。
- 纪要：记载会议主要情况和议定事项。一般不加盖印章。

## 三、用语与合规

- 用语庄重、准确、简洁，避免口语化（如“赶紧”“搞一下”）。
- 强制性表述（必须、严禁、不得）应有政策、制度或上级文件依据。
- 个人信息（手机号、身份证号等）按《个人信息保护法》最小化处理，提交前脱敏。
- 涉密、内部资料按《保守国家秘密法》标注密级，本地处理，不上传外部平台。
